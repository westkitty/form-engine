# Design critique — FORM//ENGINE studio v0.1 (before redesign)

**Reviewed from:** screenshots `artifacts/evidence/ux/before-*.png`, taken at 2960×1848, 1480×924@2x, 1024×768, 768×1024 and 390×844 (headless Chromium, live build).

**Who and why:** someone sculpting on a large Android tablet with an S Pen (Galaxy Tab S9 Ultra). They came to shape the model, and only occasionally save or export.

**Verdict:** it works, but the instrument chrome competes with the model. Three persistent zones, a 3-line HUD and nine coded brush buttons make it read like a debugger, not a sculpting surface.

## Screen critique (seven passes)

The eye lands, in order, on the right panel (Brush, Scene and Inspector stacked), then the 3-line HUD, then the top-right mode switch. The model, which is the primary surface, is fourth.

### Fix first

1. **Targets are too small for a finger or pen** (blocker on tablet). The chips are about 22 px tall, the sliders 18 px, and the tree's VIS/DEL buttons about 16 px. Android needs 48 dp. Fix: 48 px controls in a floating dock, and 28 px slider thumbs.
2. **A persistent 300 px right panel** (worth fixing, close to a blocker on a phone). Inspector transforms, the scene tree and brush help are always visible, but they're needed rarely. Fix: move them into one menu drawer with tabs (progressive disclosure).
3. **A 3-line diagnostics HUD that's always on** (worth fixing). It shows fps, BVH ms and the GPU string: noise for an artist. Fix: hide it by default, with a toggle under Settings › Show performance.
4. **Coded brush glyphs: DR, IN, CB, SM, GR, FL, PI, CR, MK** (worth fixing). Fix: drawn icons with full-word labels. Five primary brushes, and the rest behind "More".
5. **Keyboard-only copy on a touch device** (worth fixing). The "Invert: Ctrl" chip, the "Shift: smooth · Esc · [ ]" hint, and "VIS/DEL", "render verts", "Export colour". Fix: "Subtract" toggle, no hint text, "Hide/Show" and "Delete", with stats moved under Details.

### Worth fixing

- Transform modes are a persistent four-segment control, but they're used rarely. Move them into the Scene drawer, and show a "Done" chip while active.
- File and Image Lab are separate entry points. Merge them into one Menu.
- The `--faint` text #5d5b56 on #17181b is about 2.6:1 (estimated), which fails 4.5:1. Raise it to about #8a877f.

### Minor

- The brand takes prime top-left space. Shrink it and keep it.
- The grid reads as scanlines at a low camera angle (already softened).

### Working well

- The single amber accent and the hairline graphite rules: the instrument feel is worth keeping.
- The live brush ring and on-demand rendering (no idle cost).

### Could not judge

- Real S Pen hover and side-button behaviour, Samsung Internet rendering, and outdoor glare. There's no physical device.

## Flow critique

- **Main path:** open → sculpt → export (3 steps). Export sits behind File → Export GLB: 2 taps, which is fine.
- **Reference path:** File-less "Image Lab" → slots → crop → planes → reconstruct (5 steps in one dialog). That's acceptable as an advanced flow.
- **Where you lose people:** the first screen. There's too much to parse before the first stroke.
- **Cut or defer:** the brush hint text, the always-on HUD, and the always-visible inspector.

## Accessibility pass

| Check | Result |
|---|---|
| Body contrast (`--text` on panel) | pass, about 12:1 |
| Faint text | fail, about 2.6:1 → raise to about 4.6:1 |
| Non-text (borders #34373c on #17181b) | fail, about 1.5:1, but decorative. Focus ring is amber at about 8:1, pass |
| Target size | fail, 16–28 px vs 48 dp |
| Colour-only meaning | pass. Mode and selection also use outline and fill |
| Labels | partial. Icon-only undo/redo had aria-label, and slider labels are visible |
| Text scaling | not testable from images |
| Motion | pass, no autoplay |

**Blocks the most people:** target size and faint contrast.

## UI copy pass (changes made)

| Location | Before | After | Why |
|---|---|---|---|
| Brush rail | DR / CB / CR … | Draw / Clay / Crease … | codes were never taught |
| Brush panel | Invert: Ctrl | Subtract | there's no Ctrl key on a tablet |
| Brush panel | (hint line) | (cut) | it described keyboard shortcuts |
| Tree | VIS / DEL | Hide / Show, Delete | plain words |
| Inspector | Export colour | Colour | shorter, and it's the same thing |
| Top bar | File / Image Lab | Menu (File · Scene · Settings tabs) | one entry point |
| Lab | Generate editable mesh | Generate 3D model | names the outcome |
